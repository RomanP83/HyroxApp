# Fonts

Self-hosted so the build never depends on fonts.googleapis.com.

- **Archivo** (400, 500, 600, 700) — Omnibus-Type, SIL Open Font License 1.1
- **JetBrains Mono** (400, 500, 700) — JetBrains, SIL Open Font License 1.1

The files are the Latin subset served by Google Fonts for those weights.
